# Research Pack — Personas, Journeys, Interviews, Feedback (pm-skills-inspired, distilled)

Trigger: "personas", "journey map", "interview script", "analyze feedback". Distilled in own words from phuryn/pm-skills (MIT): user-personas, customer-journey-map, interview-script, sentiment-analysis. Research that feeds product-pack (personas → OST opportunities; pains → red-team evidence). Ground everything in pasted data — RAF applies.

## 1. Personas (3, data-backed)
From [pasted surveys/interviews/analytics]: pattern-match → 3 distinct personas (motivations+JTBD, not demographics). Each: name/role context · core JTBD + frequency · top 3 pains (severity) · top 3 gains (success measure) · 1 unexpected insight (counterintuitive, why it matters) · product-fit + frictions. Rules: quotes where available, distinct/non-overlapping, flag data gaps. Never invent users.

## 2. Journey Map (per persona)
Stages: Awareness → Consideration → Acquisition → Onboarding (time-to-value!) → Engagement → Retention → Advocacy. Per stage: touchpoints · user actions · thoughts/questions · emotion · pain points · opportunities. Then: aha moment, moments of truth, churn triggers. Output table Stage|Touchpoint|Action|Emotion|Pain|Opportunity + prioritized improvements (impact on conversion/retention; quick wins vs deep bets).

## 3. Interview Script (Mom Test rules)
Objectives first (decisions this informs, assumptions to validate). Opening (learning-not-selling, permission, time) → Warm-up (role, typical day) → Core JTBD, all past-tense specific: last-time walkthrough, tools used, hardest part, magic-wand change, tried-and-failed, what-good-looks-like, spend today, give-up test → Probes ("tell me more", gentle whys, specific example, what-next, feeling) → Wrap (missed anything? who else? thanks).
Rules: their life not your idea, past not future ("would you use X" is useless), 80/20 listen, never pitch, strong emotion = signal, compliments = noise. Include note template (participant/date/jobs/current/pain/outcome/willingness/surprise/follow-up).

## 4. Feedback Analysis (scale)
Ingest [CSVs/reviews/surveys] → ≥3 segments → themes per segment → sentiment −1..+1 + drivers/detractors → impact rank (frequency×severity×business) → per-segment profile (JTBD, positives, pains w/ quotes, fit, churn risk) → 2-3 improvements each (quick vs strategic). Flag small samples, minority views, feature-request vs fundamental-pain split, cross-segment patterns.

Route: interviews → personas/sentiment → journey → OST (product-pack) → prioritize → spec. Combine: RAF grounding + Research Pass rigor for disputed claims.
