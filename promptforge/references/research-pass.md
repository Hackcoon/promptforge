# Research Pass — Rigorous Investigation Protocol

Adapted from MagicalDealer/research-pass v1.0 (Public Alpha Canonical Baseline).
Source: https://github.com/MagicalDealer/research-pass
Trigger: `Research Pass this: [question, claim, observation, decision, or messy thought]`

Goal is not maximum information. Goal is **maximum useful understanding** — reduce meaningful uncertainty enough to act.

## Depth Selection (auto-choose)

- **Quick Check:** factual, definition, one claim, simple comparison → answer + qualification + sources + confidence. Do NOT turn into project.
- **Targeted Pass:** one decision, disputed claim, mechanism, focused comparison → rivals + strongest evidence + counter-evidence + mechanism + conditions + conclusion + confidence + implication.
- **Full Pass:** strategic, costly if wrong, controversial, multi-explanation, cross-disciplinary → full loop below.

## Core Loop

1. **Freeze start:** original question, current belief, confidence, assumptions, what would change conclusion. Label new ideas NEW HYPOTHESIS, never rewrite history.
2. **Classify:** descriptive / causal / mechanistic / comparative / diagnostic / predictive / strategic / evaluative — different types need different evidence. Correlation ≠ causation.
3. **Rival hypotheses:** generate alternatives. Ask: else? simultaneous mechanisms? reverse causality? third variable? selection/survivorship bias? measurement artifact? Maintain Explanation Map: Hypothesis | Mechanism | For | Against | Confidence | What would distinguish it? Best explanation = survives attempts to break it.
4. **Explanation space + vocab:** map hypotheses, mechanisms, disciplines, populations, time periods, failure cases. When new expert term appears: define it, find which discipline uses it, re-search with it. Do not stay trapped in lay wording.
5. **Search by function (not one giant search):** Background, Mechanisms, Empirical, Primary sources, Practitioner knowledge, Counter-evidence, Failure cases, History, Current state, Analogues (structural similarity, transfer mechanisms not aesthetics), User-specific evidence.
6. **Lineage + appraisal:** trace important claims to original source. 20 repeats of one stat = one source, not 20. Appraise claims individually: Rigor, Directness, Relevance, Adequacy, Coherence, Independence, Temporal fit, Incentives, Replication. Prestige ≠ applicability. Discovery ≠ proof.
7. **Triangulate + contradict:** converge independent streams (research, records, history, practitioner, user data, docs). Never hide disagreement — investigate population, context, definitions, method, time, incentives. Contradiction is information.
8. **Realist + failure check:** What works, how, why, for whom, under what conditions, compared with what, when does it fail? Actively search nulls, postmortems, edge cases, unintended consequences.
9. **Stopping rule (saturation + decision sufficiency):** stop when rivals investigated, lanes sampled, counter-evidence sought, lineage checked where it matters, new searches return known mechanisms, remaining uncertainty describable, question answerable or next action clear. If unexplored branch could change answer, continue.
10. **Synthesize:** separate Evidence (observed) / Interpretation (meaning) / Synthesis (combined view) / Hypothesis (uncertain). Do not erase uncertainty in summary.

## Confidence States

ESTABLISHED ENOUGH TO USE / STRONG WORKING CONCLUSION / PROMISING HYPOTHESIS / WEAK HYPOTHESIS / REJECTED / UNKNOWN — with why.

## Context Filter + Pressure Test

Apply to user's situation: does mechanism transfer? which assumptions hold? constraints, tradeoffs, user evidence agrees? Would conclusion change a decision — what, why, when not, what failure could it create?

## Output (Full Pass, compress if no value)

Problem, Starting belief, Rivals, Assumptions, Domain map, Search strategy, Strongest evidence, Counter-evidence, Practitioner findings, Cross-disciplinary findings, Failures, Disagreements, Mechanism model, User evidence, Synthesis, Confidence per conclusion, Practical meaning, Decision/action, Experiment/verification, What would change conclusion, Open questions, Gaps, Next branches.

## Never

Assume user right, search only confirming evidence, popularity = proof, repetition = independence, prestige = relevance, correlation = causation, hide disagreement, erase uncertainty, cite unchecked sources, pad source lists, manufacture certainty. "I don't know yet" is valid.

## How It Plugs Into This Skill

- **RAF + Research Pass:** RAF grounds in reality, Research Pass is how you get grounded for non-trivial questions.
- **QEF → Research Pass:** fix question first, then investigate.
- **TEOF High → Full Pass + HILCS:** costly errors need Full Pass + human ownership.
- **OEF after:** judge research output hard (signal, mechanism, constraint fit, reusable insight).
- **EFF guardrail:** default Quick Check. Escalate depth only on signal, per TEOF.
